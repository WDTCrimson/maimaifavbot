# tomomai Theme Preset

This preset is populated from:

- `/home/crimson/PersonalProjects/tomomai/public/res`

## Use this preset

Set in `.env`:

```env
GRAPHIC_THEME_DIR=./data/theme/tomomai
```

Then restart bot and run:

```text
/loadout graphic name:<your_loadout>
```
